# Product scope

The software implements a local development foundation for household/shared and member-private records, explicit memory/discovery/context, manual tasks/reminders, bounded document staging and a separately gated synthetic Work pilot. The generic machine scope IDs are member_a_private, member_b_private, parents_child, and member_business, alongside shared/finance/administrative scopes. The separate Work registry uses the work_private capability; it is not a household scope. This fresh schema is not a drop-in conversion of an existing private database.

Future work includes document PDF/OCR/durable archiving, scoped local-model answers, reviewed calendar/mail/notification adapters, richer domain modules and independent production/host/key/recovery acceptance. No family's circumstances, personal goals, medical/financial records or employer profile is shipped as a default configuration.
