# Selected professional review and reporting workspace

## Outcome
One coherent capability combines bounded professional-memory review, search and facets, explicit owner/due follow-up views, dated activity summaries, source/version inspection and reviewed status-report copies. Build on merged prior implementation review rather than splitting these into separate feature PRs.

## Requirements
- Current user selects 1–10 available confirmed notes from the displayed page. Existing synthetic notes/export opt-in and current authorization, revision, source, owner, retention, session/CSRF and reviewed hash checks remain authoritative. No automatic paging or claim of complete workspace coverage.
- Review the selected snapshot by text, kind, explicit owner/unknown/unavailable, source, action due-date bucket and created/updated activity window. Multiple facets intersect; counts/owner groups reflect the visible subset and identify the selected denominator. Stable citations survive filtering and sorting. Equal labels never conflate distinct owner/source IDs.
- Due classification uses the reviewed server snapshot time, never browser wall time; capture it through the fresh download so classifications do not silently shift. Past due date is not proof that an action is incomplete. Completion stays Unknown, and confirmation is not completion. Decisions/questions are notes, not inferred commitments or risks. Created/updated timestamps describe current records, not reconstructed event history or net progress.
- Explicit UTC activity bounds are half-open, finite, ordered and at most 366 days. Query/title/filters/window are ephemeral local annotations; no API/log/persistent preference content is added. Show the snapshot deadline and earliest selected copy retention.
- Produce a cited Markdown status report only after explicit review acknowledgement. Re-fetch the entire selected confirmed set with the exact reviewed hash through the existing export endpoint, then render only the reviewed visible subset using the captured filters. Include filters, window, denominator, snapshot/export provenance, unknowns, source/note revision and unmanaged-copy retention. Empty filtered views cannot be downloaded. Dynamic text escaped, generated UUID-only filename, max 64 KiB, no truncation.
- Filter/annotation edits revoke acknowledgement. Changing selection revokes snapshot and acknowledgement. Reads/writes/paging, sibling derived tools, session/workspace changes, denial, expiry, close and unmount abort/clear private review and suppress late file creation; revoke Blob URLs. Never silently reuse another derived tool's preview or acknowledgement.
- Synthetic-only; no schema/API/grant/dependency/setting change, server report store, task completion writer, model inference, connector, external send or production access. Data leaves the browser only as an explicit local unmanaged Markdown download; API receives existing IDs/revisions/hash/ack only. Real-content, original/latest/key/other-derived/full-host and retained M2 gates remain independent.

## Acceptance
Pure tests prove intersecting filters, boundary timestamps, snapshot-relative due buckets, unknown semantics, ID grouping, stable citations/sorts, defensive input validation, bounded escaped reporting and provenance. Browser coverage verifies actual HTTPS fresh download/hash/ack/annotation exclusion, controls and empty views, edits, mutual derived-tool invalidation, expiry/unmount, refusal and cancelled late backend responses. Inspect desktop/mobile screenshots. Complete make check/security/policy and all four final exact-head hosted jobs; record CI in PR metadata without an evidence-only push. ROADMAP remains unchecked until merge.
