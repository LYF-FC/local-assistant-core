# 032 — Reviewed forgetting reconciliation into older synthetic Work backups

Outcome: a trusted operator exports a complete bounded metadata manifest of terminal note/party forgetting decisions from a disabled newer synthetic workspace into a protected independent local file. After restoring an older snapshot and applying spec 031 quarantine, preview the manifest against that disabled/no-grant workspace and deliberately reapply exactly its reviewed suppressions. Preserve unrelated content and leave Work disabled with no grants. Nothing leaves the local environment.

Both sides require matching development/test target, disposable test naming, explicit actual/configured database acknowledgement, clean READ COMMITTED owner, synthetic disabled workspace and active technical-admin operator audit reference. Export includes all forgotten notes with matching tombstones and forgotten parties with matching immutable audit, capped at 25 combined decisions; reject excess or inconsistent evidence, never silently truncate. Manifest includes schema/mode, export UUID, workspace, selected operator, source database OID, generation time and ordered unique kind/UUID/forgotten revision/time. No text, labels, sources, tokens or content hashes. A domain-separated digest covers metadata only.

Files are regular, single-linked, owner-owned, owner-readable with no group/other permissions, at most 32 KiB; refuse symlinks, special files, duplicate JSON keys, malformed/extra/duplicate/unordered entries and digest mismatch. Export exclusively creates a new 0600 file, fsyncs it and its parent, never overwrites. Source audit says manifest prepared, not saved or independently backed up. The operator must protect/copy/verify the file separately. An unkeyed digest detects changes, not authenticity or completeness; a trusted operator can forge it. No bearer permission, signature, latest-ledger proof or independent backup acceptance is claimed.

Import checks workspace, future timestamps and strict manifest structure. Missing/previously forgotten items are reported; a live target at or above the source forgetting revision is a conflict, not silently deleted. At most 100 linked pending note changes/confirmations/non-null review hashes, visible in the plan; no content/hash values are read. Bind exact manifest digest, target name/OID, operator, current item state/revision, linked metadata and server issue time to a 32 KiB plan. Apply within five minutes, including final write; changed/replayed/empty plans reject. All-absent/already-forgotten with no linked effects is a no-op, not a completion receipt or a durable absent-ID ban.

Exclusive registry lock precedes workspace/operator and record/request locks. Migration 0017 admits only clean owner, disabled synthetic/no-grant, explicit restore mode, terminal forgetting; ordinary roles and normal expiry paths retain their bounds. No restore/correct/confirm/retain extension. Existing forgetting erases note current/history/review hashes and bound corrections, party labels; also deny/redact all pending note changes and confirmations tied to selected notes, even orphans. Private lifecycle audit/tombstones and metadata-only admin.work_suppression_applied receipt commit together. Guard/audit/time/commit failure rolls back; uncertain commits require metadata/receipt inspection and fresh review. Downgrade refuses reconciliation evidence.

This reconciles only supplied decisions into one selected snapshot. The manifest never expires as a forgetting decision; it cannot prove that newer decisions were not lost. Other workspaces, original sources, unbound captures, credentials/keys, jobs/approvals, derived/unmanaged exports and full-host recovery remain gates. No auto-updated independent ledger, startup enforcement, ID resurrection ban for absent records, regrant or enable is added; receipt always recovery_complete=false.

Acceptance: strict file/model/target/role/time/caps/conflict/stale/replay checks; real PG unexpired older note/party redaction, orphan/linked cleanup, unrelated preservation, audit rollback and serialization; safe upgrade/check/downgrade; actual pre-forgetting dump restored then quarantined and reconciled with a separately retained newer manifest; CLI container smoke and existing full four-job exact-head readiness gate.
