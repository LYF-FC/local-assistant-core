# Scoped document answers — spec 053

## Specify and clarify

Deliver one coherent source-backed question workflow: scoped reviewed-document retrieval, bounded evidence, an optional replaceable local answer selector, validated exact quotations/citations, visible abstention/failure and usable desktop/mobile controls. This extends specs 048/051/052 and CORE-02/06/07/10/UI-01; it does not complete general multi-turn conversation, semantic/vector retrieval, free-form synthesis or model quality acceptance. All 149 requirements remain. Installation/model research contracts remain separate, without selecting a model, downloading weights or changing a private deployment.

The default is model-disabled source search, never a fake model answer or remote fallback. An explicitly configured local-only adapter may select exact source passages or abstain; application code constructs quotations from current documents, never accepts fabricated model text, URLs or tool calls. Tests use synthetic data and a simulated local service only. Real model/license/hardware/FR/ES/EN quality evaluation and activation require separate authorization.

Accept one supported document scope, question up to 500 characters, FR/ES/EN question language (quotations preserve their original language) and bounded evidence budget (1–8 KiB). Deterministic lexical retrieval ignores a fixed small multilingual stop-word set, uses at most eight distinct terms, ranks current reviewed matches and chooses at most three documents. Each evidence window is at most eight logical lines; disclose that selection is bounded, not a comprehensive answer. Oversized windows fail without silent truncation. Preserve document/revision/raw hash, derived hash/engine/page provenance where applicable and source reference as inert text. No unreviewed, failed extraction, forgotten, unauthorized private or historical source is eligible; administration confers no content privilege.

The optional local adapter is disabled by default, has no tools/fetch/secret/database authority, uses the existing approved local address boundary and an explicit model name/digest. Verify the configured local manifest before and after selection; never pull/download/switch models, follow redirects, use environment proxies or silently retry. Bound the full local exchange to 12 seconds, each response to 32 KiB, output to five passages/8 KiB and generation/context budgets. Reject mismatched model manifests, incomplete/malformed/duplicate-key replies, unsupported fields, fake citations, invalid ranges, duplicate passages or tool calls. A valid answer contains exact selected quotations, with human review/OCR uncertainty labels; relevance and source truth remain separate quality questions.

Commit a metadata-only preparation audit before releasing evidence to the adapter. In a fresh transaction, reauthorize current session/CSRF/scope/user/configuration and lock/rebuild the exact source revisions before dispatch. Hold authority/source locks through bounded selection, recheck expiry before release, and commit result audit before response. Changed/revoked/forgotten sources prevent dispatch/release. Audit failure prevents dispatch or response as appropriate. Record only source/revision/line-range manifests and minimal operational metadata, never question, prompt, excerpt, generated text, provider error or query hash. No question/conversation/context cache or browser persistence. Responses expire within 60 seconds/session expiry; UI clears stale selections, aborts on view/scope/session changes and never auto-retries. One request uses at most one model selection and a bounded per-user request budget.

## Acceptance and checklist

Synthetic tests prove shared/private/admin/revoked/expired/CSRF/transport denial; reviewed-only lexical selection and Unicode/budget/ranking bounds; no model call when disabled/no sources; no provider before committed audit; source/configuration drift and expiry around dispatch; audit rollback; literal source instruction and malformed model refusal; exact PDF/OCR page/line/hash citations; unavailable/insufficient/conflicting states; current-source navigation, late-response suppression and mobile rendering. Exercise actual restricted PostgreSQL/locking and real simulated HTTP transport without touching a real model. Run required full checks for this authorization/backend change, existing recovery, privacy review and one completed commit/push/PR. Never merge automatically.
