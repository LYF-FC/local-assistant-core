# Spec 011 — bounded local context preview

Development/test foundation before local model integration. No semantic search, model, provider, collector, work store, standing permission or executor is activated.

C01: authenticated users explicitly choose one assigned memory-content scope and browse a bounded metadata-only catalogue (25 rows maximum) of eligible current memory. No implicit multi-scope selection, owner override, technical/work scope or automatic preview on sign-in/view entry.
C02: eligibility is stricter than ordinary Memory inspection: active, confirmed, unexpired, kind profile/preference/procedure/context; temporary context requires expiry; valid bounded title/content/source. Experience records (including Discovery proposals) and all namespaced record_type envelopes are excluded. This is not a claim to detect mislabeled work/sensitive text inside ordinary user-authored memory.
C03: preview accepts 1–10 unique explicitly selected IDs and displayed expected revisions, one scope and a bounded 512–16384-byte items budget (default 8192). Current owner/shared-scope SQL authorization is reapplied. Missing/private/wrong-scope/ineligible selection returns one generic 404 without partial payload; changed revision returns 409; over-budget returns 413 without truncation/partial context.
C04: selected rows are read-locked in deterministic UUID order through audit/commit. Every preview is rebuilt from current rows, not history or caller-supplied content. Output includes source, assessment, IDs/revisions/dates and plain reference data only; model_invoked=false, execution_allowed=false, mode=preview_only. Content is untrusted reference, never policy or executable instructions.
C05: output expires at the earliest of 60 seconds, a selected record's expiry or session absolute expiry. It is a snapshot of the authorized transaction, not a reusable access/approval token or retroactive revocation mechanism. Every new request rechecks; future inference must rebuild/re-authorize rather than accept this bundle. No bundle is persisted/exported/forwarded; only minimal IDs/revisions/count/size are audited.
C06: audit/commit failures release no preview. Use existing HTTPS Host/Origin/session/CSRF/no-store boundaries; POST preview requires CSRF even though it is a read. No schema/new grants/dependencies. Existing memory export/forget remains authoritative; old exports/backups and already-observed responses cannot be retroactively erased.
C07: session-bound Context UI shows eligible metadata, source/revision and up to ten current-page choices, byte budget, safe structured preview, clear/refresh/page/error states and automatic expiry. Scope/page/selection/budget/view/session changes clear preview; cancellation and post-await guards prevent stale responses from repopulating state. 409/denial clears selection/catalogue and requires explicit refresh. No browser storage/download/cross-tab cache.
C08: synthetic client/API/PG/real TLS browser tests verify ownership/shared scope, revocation, eligibility, bounded pagination/UTF-8 size, stale revisions, atomicity, correction races, safe text and expiry/session/scope late-response clearing. Existing migration/restore/security/browser gates remain required. Actual M2/production acceptance remains separate.
